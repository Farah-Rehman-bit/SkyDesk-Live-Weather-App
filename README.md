 SkyDesk: Live Weather App

A responsive weather dashboard built with HTML, CSS and vanilla JavaScript, using the OpenWeatherMap API.

 Features
- Search any city for temperature, conditions, humidity, wind speed and pressure
- 5-day forecast cards and dynamic weather icons
- Background gradient changes with the weather and day or night
- Loading spinner and clear error messages (unknown city, invalid key, no internet)
- °C / °F toggle, location search and recent searches
- Mobile responsive

 Tech
HTML5, CSS3 (Flexbox, Grid), JavaScript (Fetch API, async/await, try/catch)

 Run
1. Get a free key at [openweathermap.org](https://home.openweathermap.org/api_keys). It can take up to two hours to activate.
2. Open `index.html` in Chrome or Edge.
3. Paste your key, click **Save key**, then search a city.

The key is stored only in your browser. Never commit it to GitHub.

Weather data by [OpenWeatherMap](https://openweathermap.org).
